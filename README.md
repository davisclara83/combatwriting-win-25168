## About Combat Writing

Combat Writing is built for communication work where clarity, structure, and revision discipline matter. It brings a practical writing methodology into a lightweight single-file app that can run on desktop without extra installation steps or package management overhead.

The tool is designed for writers, operators, and teams who need to shape drafts, review language, and move from rough text to finished output in a controlled workflow. With offline-capable use and support for both local and cloud AI options, it fits environments where internet access may be limited or where a compact deployment is preferred.
